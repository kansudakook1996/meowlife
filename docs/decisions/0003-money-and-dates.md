# ADR 0003 — เงินเป็นสตางค์จำนวนเต็ม, วันที่เป็น `YYYY-MM-DD`

- สถานะ: ยอมรับ (2026-10-28)

## เงิน
- เก็บและคำนวณเป็น **สตางค์ (INTEGER)** ตลอดทาง: ฐานข้อมูล → IPC → UI
- แปลงข้อความ ↔ สตางค์ด้วยสตริง/regex (`parseBahtToSatang`) ไม่ผ่าน `parseFloat`
- ทศนิยมเกิน 2 ตำแหน่ง = ไม่ยอมรับ (ไม่ปัดเศษเงียบ ๆ)
- สูงสุดต่อรายการ 999,999,999.99 บาท ⇒ ผลรวมยังอยู่ใน `Number.MAX_SAFE_INTEGER` สบาย ๆ
- ทางเลือกที่ไม่เลือก: decimal library (เกินความจำเป็นสำหรับสกุลเงินเดียวและไม่มีการหาร), BigInt (ส่งผ่าน IPC/JSON ยาก)

## วันที่
- `YYYY-MM-DD` เป็นวันตามปฏิทินท้องถิ่น ไม่มีเวลา/โซนเวลา — เพราะ "วันที่จ่ายบิล" คือวันในปฏิทิน ไม่ใช่ช่วงเวลา
- คำนวณระยะห่างวันผ่าน `Date.UTC` เพื่อไม่ให้ DST/โซนเวลาเลื่อนวัน
- แสดงผลแบบ พ.ศ. ด้วย `Intl.DateTimeFormat('th-TH')`
- timestamps ระบบ (`created_at`, `updated_at`) เป็น ISO UTC สำหรับ sync
