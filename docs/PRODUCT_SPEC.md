# MeowLife — Product Spec

> Personal Portal สำหรับจัดการชีวิตส่วนตัวบน Windows: บัญชีรายรับรายจ่ายเป็นแกนหลัก
> แล้วขยายเป็นปฏิทิน บันทึก เป้าหมาย นิสัย และสถิติ ในแอปเดียว

## 1. ผู้ใช้เป้าหมาย
- คนทั่วไปในประเทศไทยที่เคยจดรายรับรายจ่ายใน Excel และอยากได้เครื่องมือที่ง่ายกว่า
- ต้องเข้าใจได้แม้เด็กอายุ 10 ขวบ: คำสั้น ปุ่มชัด ฟอร์มน้อยช่อง
- ใช้งานออฟไลน์ได้เต็มที่ ซิงก์ข้ามเครื่องเมื่อเข้าสู่ระบบ (ไม่บังคับ)

## 2. หลักการออกแบบ
1. **ข้อมูลถูกต้องก่อนความสวย** — เงินคำนวณเป็นสตางค์ ไม่มีปัดเศษเพี้ยน
2. **ไม่หลอกผู้ใช้** — ไม่มีข้อมูลตัวอย่างปนข้อมูลจริง ไม่มีปุ่มที่กดแล้วไม่ทำอะไร
3. **ไม่กดดัน** — แมวคู่ใจให้กำลังใจ ไม่ตำหนิเมื่อใช้เงินเกิน
4. **ย้อนกลับได้** — ยืนยันก่อนลบ, Undo, Backup อัตโนมัติก่อน Restore

## 3. โมดูลและลำดับความสำคัญ

### 3.2 บัญชีผู้ใช้และซิงก์ (M4)
- Firebase Authentication (อีเมล/รหัสผ่าน) — ไม่บังคับ ใช้แบบไม่ล็อกอินได้
- Cloud Firestore เก็บข้อมูลภายใต้ `users/{uid}/...` เท่านั้น
- Sync: ทำงานเบื้องหลัง, Retry, แสดงสถานะ, ข้อมูลขัดแย้งต้องไม่หายเงียบ ๆ

### 3.3 Release และอัปเดต (M5)
- Installer `.exe` (NSIS) ผ่าน electron-builder
- GitHub Actions สร้าง Release เมื่อ push tag `vX.Y.Z`
- electron-updater ตรวจและติดตั้งเวอร์ชันใหม่ ข้อมูลในเครื่องต้องไม่หาย

### 3.4 Personal Portal (M6+ หลังบัญชีเสถียร)
Calendar (เดือน/สัปดาห์/วัน), Daily Journal + อารมณ์, Tasks + งานประจำ, Goals + เป้าหมายการออม,
Habits + สถิติ, Notes + ค้นหา, Insights, Reminder, Cat Companion (Badge + คำให้กำลังใจ), Settings

## 4. นิยามยอดเงินบน Dashboard (ของเดือนที่เลือก)
ดูสูตรละเอียดใน `DATA_MODEL.md` §4
- **รายรับ** = ผลรวมรายการรายรับทั้งหมดในเดือน (แสดง "ได้รับแล้ว" แยก)
- **รายจ่าย** = ผลรวมรายการรายจ่ายทั้งหมดในเดือน (แสดง "จ่ายแล้ว" แยก)
- **คงเหลือ** = รายรับ − รายจ่าย (ติดลบได้ แสดงชัดเจน)
- **ค้างชำระ** = ผลรวมรายจ่ายที่ยังไม่จ่าย (แสดงจำนวนที่เกินกำหนด)

## 5. ข้อมูลอ้างอิงจาก Excel ของเจ้าของ
เจ้าของโปรเจกต์จะส่งภาพ Excel เดิมเพื่อใช้อ้างอิง Workflow และรายการ (ยังไม่ได้รับ ณ 2026-10-28)
เมื่อได้รับให้บันทึกการ map คอลัมน์ไว้ใน `DATA_MODEL.md` §6 — ไม่ลอกหน้าตา Excel

## 6. นอกขอบเขต (ตอนนี้)
- หลายสกุลเงิน, หลายผู้ใช้ในบัญชีเดียว, เชื่อมธนาคารอัตโนมัติ, macOS/Linux build
