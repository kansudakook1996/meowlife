## ตรวจสอบจริงแล้ว
- `npm run verify` ผ่าน: lint, typecheck, unit tests **173 ข้อ**, build
- E2E บนแอปจริง **17 ข้อ**: บัญชี, รายการประจำ, หมวดหมู่, นำเข้า/ส่งออก/สำรอง/กู้คืน, รายงาน, เลย์เอาต์ 900×600 ทุกหน้า (15 หน้า),
  งาน (ทำซ้ำ/เลิกทำ), บันทึก, เป้าหมาย, นิสัย, โน้ต, ปฏิทิน 3 มุมมอง, สถิติ, แมวคู่ใจ, ตั้งค่า (ธีม/ปี/เงิน คงอยู่หลังเปิดใหม่)
- `npm run test:rules` (Firestore Emulator) ผ่าน **17 ข้อ**: Rules ทุกคอลเลกชัน (รวมของใหม่) และซิงก์ 2 เครื่องผ่าน Firestore จริง
- ซิงก์กับ Firebase จริงบนแอปที่ติดตั้ง v0.2.0 ผ่าน (เจ้าของยืนยัน 2026-10-29)

## ยังไม่ได้ทำ / ข้อจำกัด (พูดตามจริง)
- **ซิงก์ข้ามเครื่องจริง** และการสลับออฟไลน์จริงในแอป ยังไม่เคยทดสอบ (มีเฉพาะเครื่องจำลอง + Emulator)
- **อัปเดตแบบเงียบ** (`quitAndInstall(true, true)`) ยังไม่เคยทดสอบ — 0.2.0 → 0.3.0 จะเป็นครั้งแรก; ตัวติดตั้งเป็น per-machine อาจขึ้น UAC
- **แจ้งเตือนบน Windows**: โค้ดและตรรกะมีเทสต์ แต่การแสดง toast จริงของ Windows ยังไม่ได้ตรวจด้วยตา (ขึ้นกับ Focus Assist/โหมดห้ามรบกวน) และทำงานเฉพาะตอนเปิดแอป
- ตั้งค่าไม่ซิงก์ข้ามเครื่อง (เก็บเฉพาะเครื่อง); ฐานข้อมูล/ไฟล์สำรองไม่เข้ารหัส; ข้อมูลบน Firestore ไม่เข้ารหัสฝั่งแอป
- ปฏิทินยังไม่มีการลากวาง/สร้างบิลจากปฏิทิน; งานทำซ้ำรายเดือนวันที่ 31 จะค่อย ๆ เลื่อนเป็นวันที่ 28 หลังผ่านเดือนกุมภาพันธ์
- ไม่รองรับไฟล์ .xls; เปลี่ยนบัญชีออนไลน์บนเครื่องเดิมไม่ได้ (ป้องกันข้อมูลปนกัน)
- ตัวติดตั้งไม่ได้ Code Sign → SmartScreen เตือน
- ยังไม่ได้ทดสอบกับโปรแกรมอ่านหน้าจอ และยังไม่ได้ไล่ Tab ทุกหน้าด้วยมือ (E2E ใช้ aria-label/role ครบแล้ว)
