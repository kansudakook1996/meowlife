## ตรวจสอบจริงแล้ว
- `npm run verify` ผ่าน (lint, typecheck, unit tests 136 ข้อ, build)
- E2E บนแอปจริง 9 ข้อ: บัญชี, รายการประจำ, หมวดหมู่, นำเข้า CSV, ส่งออก, สำรอง/กู้คืน, รายงาน, เลย์เอาต์ 900×600 ทุกหน้า, การ์ดบัญชีออนไลน์
- `npm run test:rules` (Firestore Emulator + Java 21) ผ่าน 15 ข้อ: Rules กันคนอื่น/คนไม่ล็อกอิน, เอกสารจริงของแอปผ่านกฎ,
  และซิงก์ 2 เครื่องผ่าน Firestore จริง (คำสั่ง query/batch จริง) ทั้งเพิ่ม แก้ ลบ ขัดแย้ง รายการประจำ
- Firebase Auth + ปุ่มทดสอบการเชื่อมต่อ ผ่านบนแอปที่ติดตั้ง (เจ้าของยืนยัน 2026-10-28)
- ติดตั้งและอัปเดตจาก GitHub Releases จริง (0.1.0 → 0.1.2) ข้อมูลไม่หาย

## ยังไม่ได้ทำ / ข้อจำกัด
- ซิงก์กับ Firebase จริง (เครือข่าย + Auth) บน 2 เครื่อง — ต้องให้เจ้าของลองตามคู่มือ
- ตัวนับถอยหลัง retry ใน UI และการสลับออนไลน์/ออฟไลน์ในแอปจริง ยังไม่มีเทสต์อัตโนมัติ (ตรรกะ retry มีเทสต์)
- อัปเดตแบบเงียบ (`quitAndInstall(true, true)`) ยังไม่เคยทดสอบจริง; ตัวติดตั้งติดตั้งแบบ per-machine จึงอาจขึ้น UAC
- ไฟล์ .xls (Excel เก่า) ไม่รองรับ; นำเข้าได้ครั้งละไม่เกิน 20,000 แถว / 15 MB
- ฐานข้อมูลและไฟล์สำรองไม่ได้เข้ารหัส; ข้อมูลบน Firestore ไม่ได้เข้ารหัสฝั่งแอป
- เปลี่ยนบัญชีออนไลน์บนเครื่องเดิมไม่ได้ (ฐานข้อมูลผูกกับบัญชีแรก) — ออกแบบไว้เพื่อป้องกันข้อมูลปนกัน
- ยังไม่มีหน้าตั้งค่าธีม/รูปแบบวันที่/จำนวนวัน "ใกล้ครบกำหนด"
- ตัวติดตั้งไม่ได้ Code Sign → SmartScreen เตือน
