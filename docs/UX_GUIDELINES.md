# UX Guidelines

## โทนและภาษา
- เป็นมิตร สั้น ชัด เหมือนเพื่อนอธิบาย: "เพิ่มรายการ", "จ่ายแล้ว", "ยังไม่มีรายการเดือนนี้"
- ไม่ตำหนิ: ใช้ "เดือนนี้ใช้มากกว่ารายรับนิดหน่อย ค่อย ๆ ปรับกันนะ" แทน "คุณใช้เงินเกิน!"
- ตัวเลขเงินแสดง `฿1,234.50` เสมอ (มีทศนิยม 2 ตำแหน่ง)
- วันที่แสดงแบบไทย พ.ศ. เช่น "28 ต.ค. 2569"

| Token | ค่า | ใช้กับ |
|---|---|---|
ปรับให้เข้มขึ้นตามคำขอเจ้าของ (v0.1.1) ค่าจริงอยู่ใน `src/renderer/src/styles/theme.css`

| `--pink-100/300/500/700` | #FFD3E3 / #FF9CBD / #C93D72 / #A02F5C | ปุ่มหลัก (ขาวบน 500 = 4.8:1), แมว, รายจ่าย |

| `--blue-100/300/600` | #D2E9FF / #8CC4FB / #24609E | รายรับ, ลิงก์, โฟกัส |

| `--red-100/600` | #FFD8D3 / #A8231B | เกินกำหนด, ลบ |

## สถานะ — สี + ไอคอน + ข้อความ เสมอ
| สถานะ | ไอคอน | ข้อความ (รายจ่าย / รายรับ) | สี |
|---|---|---|---|
| paid | ✓ | จ่ายแล้ว / ได้รับแล้ว | เขียว |
| unpaid | ○ | ยังไม่จ่าย / ยังไม่ได้รับ | เทา-ฟ้า |
| due_soon | ⏰ | ใกล้ครบกำหนด (อีก N วัน / วันนี้) | เหลือง |
| overdue | ! | เกินกำหนด N วัน | แดง |

## ฟอนต์
1. **"Lmf_ Wanpharuehat Demo"** — ฟอนต์ลายมือที่เจ้าของเลือก (v0.1.1) **ไม่ได้แนบมากับแอป**
   - เป็นรุ่น Demo, ไม่มีใบอนุญาตให้แจกต่อ (ในไฟล์เขียนว่า "ห้ามนำเทมเพลไปใช้งานโดยเด็ดขาด")
     จึงติดตั้งไว้เฉพาะเครื่องเจ้าของที่ `%LOCALAPPDATA%\Microsoft\Windows\Fonts\WanpharuehatDemo.ttf`
   - ไฟล์ต้นฉบับ `Wanpharuehat.zip` อยู่ในโฟลเดอร์โปรเจกต์ แต่ถูก `.gitignore` (ห้าม commit)
   - มีแค่น้ำหนัก Regular → ใช้ `font-synthesis-weight: none` เพื่อไม่ให้ตัวหนาปลอมเลอะ
   - ขาดเฉพาะเครื่องหมายหายาก (ฺ ๎ ๏ ๚ ๛) — เบราว์เซอร์จะใช้ฟอนต์ถัดไปแทนเฉพาะตัวนั้น
   - ถ้าจะใช้ในเวอร์ชันที่แจกคนอื่น ต้องซื้อ/ขอใบอนุญาตแบบ embed/แจกจ่ายก่อน
2. สำรองที่ฝังในแอป (ทำงานออฟไลน์ทุกเครื่อง): **Mali** (หัวข้อ) และ **Sarabun** (เนื้อหา) — Cadson Demak, SIL OFL 1.1
   ติดตั้งผ่าน `@fontsource/*`

## แมวคู่ใจ "โมจิ"
- ภาพ SVG ต้นฉบับ วาดในโปรเจกต์นี้ (`CatMascot.tsx`) มีอารมณ์ `happy`, `sleepy`, `cheer`, `worried`
- โผล่ใน Empty State, Dashboard และ Toast — ไม่บังหน้าจอ ไม่ขยับรบกวน

## การโต้ตอบ
- ปุ่มหลัก 1 ปุ่มต่อหน้า (สีชมพู), ปุ่มรองเป็นขอบ
- ฟอร์มสั้น: ช่องจำเป็นมีแค่ ประเภท, ชื่อ, จำนวนเงิน, วันที่ — ที่เหลือพับไว้ใต้ "รายละเอียดเพิ่มเติม"
- ลบ: กล่องยืนยัน → Toast "ลบแล้ว" พร้อมปุ่ม "เลิกทำ" 8 วินาที
- คีย์ลัด: `Ctrl+N` เพิ่มรายการ, `Ctrl+F` ค้นหา, `Esc` ปิดกล่อง, `Enter` บันทึกฟอร์ม
- Focus ring ชัด (`outline: 3px solid var(--blue-600)`), Tab order ตามลำดับสายตา
- ขนาดหน้าต่างขั้นต่ำ 900×600; เนื้อหายืดตามหน้าต่าง
