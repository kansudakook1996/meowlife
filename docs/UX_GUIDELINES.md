# UX Guidelines

## โทนและภาษา
- เป็นมิตร สั้น ชัด เหมือนเพื่อนอธิบาย: "เพิ่มรายการ", "จ่ายแล้ว", "ยังไม่มีรายการเดือนนี้"
- ไม่ตำหนิ: ใช้ "เดือนนี้ใช้มากกว่ารายรับนิดหน่อย ค่อย ๆ ปรับกันนะ" แทน "คุณใช้เงินเกิน!"
- ตัวเลขเงินแสดง `฿1,234.50` เสมอ (มีทศนิยม 2 ตำแหน่ง)
- วันที่แสดงแบบไทย พ.ศ. เช่น "28 ต.ค. 2569"

## สี (CSS variables ใน `theme.css`) — ตามไอคอนแมวขาว/ส้มของเจ้าของ (v0.1.4)

|---|---|---|

| `--orange-50/100/300/500/700` | #FFF4E8 / #FFE3C7 / #F7A55A / #E98A2E / #B4530F | แมวส้ม (500), **ปุ่มหลัก `--primary` = 700** (ขาวบนส้ม 5.0:1) |

| `--pink-100/300/700` | #FFD9E4 / #F7A6BD / #A02F5C | รายจ่าย (สีมีความหมาย ไม่ใช่สีแบรนด์) |
| `--blue-100/300/600` | #D6EBFF / #8CC4FB / #24609E | รายรับ, ลิงก์, โฟกัส |

| `--red-100/600` | #FFDAD4 / #A8231B | เกินกำหนด, ลบ |

## ดีไซน์ "สดใส" (v0.4.0) — เจ้าของเลือกพาเลตต์เอง
สีหลัก: ชมพู `#F188A7` · ฟ้า `#84CFEE` · กรมท่า `#273564` (ขอบเส้น เงา และตัวอักษร) · ขาว · เทาแมว `#BDBDBB` ·
น้ำเงิน `#406AB2` · ฟ้าเทา `#788FB8` · น้ำเงินเทาหม่น `#5E749A` (ข้อความรอง) — กำหนดเป็นตัวแปรใน `theme.css`
- สไตล์: พื้นสีเรียบ + ขอบกรมท่า 2px + เงาแข็ง (3px 3px 0) แบบสติกเกอร์ มุมโค้ง 8–14px ปุ่มหลักสีชมพู **ตัวอักษรกรมท่า** (ขาวบนชมพูตัดกันแค่ ~2.3:1)
- ไอคอนเมนูเป็น SVG เส้น (`components/Icon.tsx`) ไม่ใช้อีโมจิในแถบนำทาง; ตัวอักษรเมนู 0.84rem; เมนูต้อง **เห็นครบไม่ต้องเลื่อน** ที่ 900×600 (มีเทสต์ใน `layout.spec.ts`)
- ข้อยกเว้นเพื่อการอ่านออก: ตัวเลขรายจ่ายที่เป็นข้อความใช้ชมพูเข้ม `#B23A5F` (ชมพูหลักบนขาวอ่านยาก); สีสถานะ เขียว/เหลือง/แดง คงเดิม
- ความสะดวกใช้งาน: แถบบนทุกหน้ามี "ค้นหา / สั่งงาน (Ctrl+K)" กับ "เพิ่มรายการ (Ctrl+N)"; Ctrl+K เรียงผลที่ขึ้นต้นด้วยคำที่พิมพ์ก่อน; แอปจำหน้าล่าสุด;
  กล่องโต้ตอบทุกอันโฟกัสช่องแรกให้พิมพ์ได้ทันที; หน้าภาพรวมมีทางลัดจดรายจ่าย/รายรับ

### ธีมสี (ตั้งค่า → ธีมสี) — ปัจจุบันมี "สดใส" และ "อบอุ่น" (ส่วนล่างนี้เป็นรายละเอียดของธีมเดิม v0.3.0 เก็บไว้เป็นประวัติ)
- `orange` (ค่าเริ่มต้น, ตามแมว), `pink`, `blue` — เปลี่ยนเฉพาะสเกล `--orange-*` (สีหลัก/ปุ่ม), พื้นหลัง และแถบเมนู ผ่าน `:root[data-theme]` ใน `theme.css`
- สีสถานะ (เขียว/เหลือง/แดง) สีรายรับ-จ่าย และสีแมวส้ม **ไม่เปลี่ยน** ตามธีม เพื่อให้ความหมายคงที่
- ปุ่มหลักต้องมีคอนทราสต์ ≥ 4.5:1 กับตัวอักษรขาวในทุกธีม (ส้ม 5.0, ชมพู ~6, ฟ้า ~6.6)

## ข้อความแจ้งเตือน (toast)
มุมขวาล่าง แสดงสูงสุด 2 อัน อยู่นาน 7 วินาที และ **ไม่รับคลิกบริเวณว่าง** เพื่อไม่บังปุ่มด้านล่าง (เคยบังปุ่มบันทึกนานหลายวินาที)

## สถานะ — สี + ไอคอน + ข้อความ เสมอ
| สถานะ | ไอคอน | ข้อความ (รายจ่าย / รายรับ) | สี |
|---|---|---|---|
| paid | ✓ | จ่ายแล้ว / ได้รับแล้ว | เขียว |
| unpaid | ○ | ยังไม่จ่าย / ยังไม่ได้รับ | เทา-ฟ้า |
| due_soon | ⏰ | ใกล้ครบกำหนด (อีก N วัน / วันนี้) | เหลือง |
| overdue | ! | เกินกำหนด N วัน | แดง |

## การโต้ตอบ
- ปุ่มหลัก 1 ปุ่มต่อหน้า (สีส้มเข้ม `--primary`), ปุ่มรองเป็นขอบส้มอ่อน
- ฟอร์มสั้น: ช่องจำเป็นมีแค่ ประเภท, ชื่อ, จำนวนเงิน, วันที่ — ที่เหลือพับไว้ใต้ "รายละเอียดเพิ่มเติม"
- ลบ: กล่องยืนยัน → Toast "ลบแล้ว" พร้อมปุ่ม "เลิกทำ" 8 วินาที
- คีย์ลัด: `Ctrl+N` เพิ่มรายการ, `Ctrl+F` ค้นหา, `Esc` ปิดกล่อง, `Enter` บันทึกฟอร์ม
- Focus ring ชัด (`outline: 3px solid var(--blue-600)`), Tab order ตามลำดับสายตา
- ขนาดหน้าต่างขั้นต่ำ 900×600; เนื้อหายืดตามหน้าต่าง
